# Project Overview

Hermes Community Edition is a public bootstrap project for running a practical Hermes setup with the lowest possible barrier to entry.

## Mission

Make it possible for a non-specialist user to get a working Hermes agent by:

1. Downloading or cloning this repo.
2. Creating their own OpenRouter account.
3. Creating an API key.
4. Running a guided installer.
5. Starting Hermes with a free-capable model route.

## Target users

- Beginners who want to try an agent without building an AI stack.
- Technical users who want a quick Hermes bootstrap.
- Consultants who want a demo-friendly public starter kit.
- Small businesses exploring AI agents without large up-front spend.
- Homelab users who want to extend the setup into always-on infrastructure.

## Product principles

- Be honest about cost.
- Do not pretend cloud hosting is permanently free when it is trial-credit based.
- Do not automate account creation where users must create their own account.
- Keep secrets local.
- Make the free local path the default.
- Treat server deployment as advanced.
- Treat production/client use as a later hardened path.

## MVP scope

The MVP provides:

- Linux installer script.
- macOS installer script.
- Windows PowerShell installer script.
- OpenRouter environment template.
- Owl Alpha default model setting.
- Local documentation.
- Cloud deployment planning docs.

## Out of scope for MVP

- Fully signed GUI installers.
- Production managed appliance support.
- Billing integration.
- OpenRouter account creation automation.
- Automatic provider account creation.
- Business data compliance certification.

## Success criteria

A first-time technical user should be able to:

- clone the repo,
- run the installer,
- paste an OpenRouter key,
- confirm the local environment is configured,
- and understand the next steps for Hermes.

A future non-technical user should be able to:

- download a Windows or macOS installer,
- follow a wizard,
- paste an OpenRouter key,
- and start Hermes without using a terminal.
