# Code of Conduct

Hermes Community Edition is intended to be useful, welcoming, and beginner-friendly.

## Expected behaviour

- Be respectful and constructive.
- Assume good intent.
- Help beginners without gatekeeping.
- Keep discussions focused on improving the project.

## Unacceptable behaviour

- Harassment or abuse.
- Sharing private information without permission.
- Posting secrets, keys, or credentials.
- Deliberately misleading users about costs or provider limits.

## Reporting

Report behaviour concerns to the project maintainer through GitHub.
