# Oracle Free Tier Deployment

This is a planned experimental deployment path.

## Positioning

Oracle Free Tier can be attractive for permanent free hosting, but capacity, availability, account approval, and regional limits can vary.

## Target architecture

- Oracle Cloud Always Free eligible VM where available
- Ubuntu or Oracle Linux
- Hermes installed as a service
- OpenRouter Owl Alpha as hosted model
- Tailscale optional for private access

## Risks

- Free capacity may not be available in every region.
- Small instances may have limited RAM and CPU.
- Users may need to understand cloud networking and SSH.

## Status

Not implemented yet. Use the local installer first.
