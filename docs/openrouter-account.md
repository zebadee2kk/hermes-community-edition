# OpenRouter Account and API Key

Hermes Community Edition uses OpenRouter as an OpenAI-compatible hosted model provider.

## Steps

1. Go to https://openrouter.ai
2. Sign in or create an account.
3. Go to https://openrouter.ai/settings/keys
4. Create a new API key.
5. Copy the key once and keep it private.
6. Paste it into the Hermes Community Edition installer when prompted.

## Recommended settings

Where OpenRouter allows it, use spending limits or credit limits to avoid unexpected costs.

## Default model

This project currently defaults to:

```text
openrouter/owl-alpha
```

## Important

Do not paste your API key into GitHub issues, pull requests, screenshots, public chats, or documentation.
