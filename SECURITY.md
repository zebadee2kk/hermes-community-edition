# Security Policy

Hermes Community Edition is an early-stage bootstrap project.

## Reporting

Please use GitHub's private security advisory feature if available. Otherwise, contact the maintainer directly.

## Do not post publicly

Please do not include the following in public issues, pull requests, comments, screenshots, or logs:

- API keys
- access tokens
- passwords
- private customer information
- private URLs
- screenshots containing account details

## Local configuration

The installer creates local configuration files such as `.env`. These files are ignored by Git and should remain on the user's own device.

## Hosted model caution

Users should review provider privacy, retention, logging, and billing terms before sending sensitive information to any hosted model.
