# FAQ

## Is this completely free?

The local bootstrap is free. It uses your own computer and a free-capable hosted model route. Third-party model/provider availability can change, so always check the provider account page.

## Does this create an OpenRouter account for me?

No. You create your own account and API key. The installer only helps configure your local machine.

## Does this include Hermes Desktop?

Not yet as a packaged one-click installer. The MVP focuses on local CLI bootstrap first.

## Can non-technical users use this?

That is the goal. The current repo is the technical MVP. GUI installers for Windows and macOS are planned after the CLI flow is stable.

## Can I use this for client data?

Not by default. Review privacy, logging, data processing, and contractual terms first.

## Can I run it on a server?

Yes, but that is an advanced path. Start with the local install, then review the cloud docs.
