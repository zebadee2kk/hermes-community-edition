# Contributing

Thanks for helping improve Hermes Community Edition.

## Priorities

1. Keep the local install path simple.
2. Do not add real credentials or personal configuration.
3. Prefer clear documentation over clever automation.
4. Keep non-technical users in mind.

## Development flow

- Open an issue before large changes.
- Use small pull requests.
- Explain which platform you tested on.
- Include screenshots or logs only after removing private information.

## Good first contributions

- Improve Windows installer reliability.
- Improve macOS installer reliability.
- Test Linux distributions.
- Improve troubleshooting docs.
- Add GUI installer research notes.
- Add cloud deployment validation.

## Commit style

Use clear commit messages, for example:

```text
Add Windows installer bootstrap
Document OpenRouter key setup
Add DigitalOcean deployment notes
```
